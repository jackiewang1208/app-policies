简要说明

Arrow Trails 是一款离线益智游戏。游戏进度和偏好保存在你的设备上，不会向我们发送游戏数据。发送邮件或访问本网页会涉及独立服务，详情见下文。

01 · 关于我们

本政策适用于由 Jackie Liao（下称“我们”）开发和提供的 Arrow Trails（中文名“箭径”）当前 Android 离线版本，同时说明你联系我们或访问本隐私政策网站时的信息处理方式。

02 · 设备上的数据

游戏会在应用的本地存储中保存以下内容：

  • 已完成的关卡及最佳星级，用于记录进度和解锁关卡。
  • 尚未完成的局面，包括操作记录、失误次数、提示使用情况及剩余计时，以便继续游戏。
  • 语言和触感反馈偏好，用于记住你的设置。

上述记录用于设备上的游戏功能，我们不会接收这些记录。游戏不提供开发者运营的云存档、账号系统或跨设备同步。

03 · 收集与共享

游戏不会向我们收集或传输个人信息，不包含广告、用户分析、追踪或第三方崩溃上报 SDK，也不收集广告标识符、位置、通讯录、照片或支付信息。

我们不出售个人信息，也不向广告商或数据经纪商共享游戏记录。你主动通过邮件提供的信息，按第 06 节单独处理。

04 · 权限与安全

游戏无需访问摄像头、麦克风、位置、通讯录或共享照片与文件。本地存档位于应用的私有存储空间，并使用 Android 提供的访问保护。游戏已配置为将存档排除在 Android 云备份和设备迁移之外。

我们无法访问或远程恢复你的本地存档。设备安全和访问控制有助于保护这些数据，但任何存储或通信方式都无法保证绝对安全。

05 · 保留与删除

本地进度和偏好会保留至游戏过程中被更新或被删除。你可以进入 Android 的设置 → 应用 → Arrow Trails → 存储 → 清除存储空间／清除数据来删除记录，具体菜单名称可能因设备而异。卸载应用通常也会移除本地数据。

删除数据会重置你的进度和设置，我们没有可供恢复的服务器副本。游戏没有需要注销的账号。如你通过设备工具自行建立了副本，需通过相应工具管理这些副本。

06 · 邮件联系

如果你给我们发送邮件，我们会收到你的邮箱地址、邮件正文，以及你主动提供的信息或附件。我们仅将其用于回复、调查问题和处理隐私请求。请勿发送密码或不必要的敏感信息。

邮件服务提供商会为收发和存储邮件处理这些通信内容。我们仅在处理你的请求及履行适用法律义务所需的期间保留邮件，之后删除。你可以通过下方邮箱申请访问、更正或删除相关信息，具体依适用法律处理。我们不会将支持邮件用于广告。

07 · 网页与其他服务

本隐私政策网站由 GitHub Pages 托管。我们没有在这些页面中添加广告、统计脚本、追踪像素或 Cookie。访问网页时，GitHub 可能为提供和保护服务而处理 IP 地址等技术请求信息，详见 GitHub 隐私声明。

操作系统、应用商店及邮件服务提供商可能根据各自的政策和你的设置独立处理信息。这些服务与游戏本地存档相互独立。

08 · 儿童隐私

游戏无需账号、不进行追踪的设计适用于所有玩家。我们不会通过游戏有意收集儿童的个人信息。如果家长或监护人认为儿童通过邮件向我们发送了个人信息，请联系我们，以便核查并适当删除。

09 · 政策变更

当应用功能或数据处理方式改变时，我们可能更新本政策。更新后的内容会发布在本地址，并修改更新日期。如变更需要额外通知或同意，我们会按要求提供。本政策描述的是当前离线游戏，不代表未来可能新增的功能。
